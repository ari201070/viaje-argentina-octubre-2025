# Argentina – Aventura Familiar de 30 Días

Aplicación Open Source desarrollada con React + Vite.

## Objetivos

- Diario del viaje
- Información por ciudad
- Mapas OpenStreetMap
- Galería
- Modo Offline
- Español / Hebreo / Inglés
- IA local
- Exportación PDF

## Stack

- React
- Vite
- OpenStreetMap
- Leaflet
- GitHub
